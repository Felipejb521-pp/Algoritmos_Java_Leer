# Unidad 6: Entrada de Datos por Teclado y Validaciones - Ud6

Este repositorio contiene el proyecto **Ud6**, que reúne los ejercicios prácticos de la asignatura de **Programación** de 1.º del Grado Superior en **Desarrollo de Aplicaciones Multiplataforma (DAM)**.

## Contenido

El proyecto aborda la interacción con el usuario por consola y el control de restricciones mediante Java moderno:

* **Lectura por Consola:** Uso de la clase auxiliar `Leer.java` (proporcionada en clase) para la captura por teclado de tipos primitivos (`int`, `double`, `char`, etc.) y cadenas (`String`).
* **Gestión de Restricciones:** Validación de datos introducidos por el usuario (rangos, límites de valores y menús interactivos).
* **Control de Flujo:** Estructuras repetitivas y condicionales adaptadas a la interacción continua con el usuario.

## Entorno de Desarrollo

* **IDE:** Apache NetBeans IDE 27
* **JDK:** Java SE 24
